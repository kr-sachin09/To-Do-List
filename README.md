# To-Do List Web App 📝

A clean, interactive, and responsive To-Do List application designed to help users manage their daily tasks efficiently. This project was built entirely from scratch using core web technologies to practice DOM manipulation and event handling.

## 🛠️ Built With
* **HTML5:** For structuring the layout.
* **CSS3:** For styling, layout, and responsive design.
* **JavaScript (Vanilla):** For dynamic task management and DOM manipulation.

## ✨ Features
* **Add Tasks:** Quickly add new tasks to your list.
* **Mark as Complete:** Check off tasks as you finish them.
* **Delete Tasks:** Remove items you no longer need.
* **Responsive Design:** Works beautifully on both desktop and mobile devices.
* **Local Storage:** Tasks are saved in your browser, so you don't lose them when you refresh the page.
